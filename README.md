# 菌棒档案台 · 大棚三维巡检系统

面向山地香菇基地的网页版菌棒档案与三维巡检系统。40 个大棚、40 万根菌棒全部实例化渲染，
状态数据在 WebGPU 存储缓冲与 IndexedDB 之间共用同一份二进制布局，按天推进由计算着色器批量完成。

## 技术栈

- TypeScript 5 + Vite 6，零运行时框架依赖，原生 DOM 组件
- WebGPU：存储缓冲 + 计算着色器（状态推进、视锥/遮挡剔除、压缩、间接绘制）
- IndexedDB：菌棒二进制记录分块持久化（每块 5 万根），配置/工单独立 store
- 无 WebGPU 环境自动降级 Canvas2D，业务流程不受影响

## 六个页面

| 页面 | 能力 |
| --- | --- |
| 基地总览 | KPI、全基地状态分布、40 栋大棚热力卡片（按待办/污染分深浅），点击直飞该棚三维 |
| 大棚档案 | 棚参数、温湿度、层架排布编辑，保存后按统一格位映射重排，容量不足拒绝，杜绝重格 |
| 菌棒批次 | 16 个接种批次跨棚追溯，单棒档案编号查询并可在三维中定位 |
| 三维巡检 | 40 万根实例化、ID 缓冲拾取、框选批量改状态、绿霉高风险高亮、状态时间线 |
| 农事任务 | 按状态自动派单（补水/翻棒/采菇/清污染），按棚按排聚合，潮次产量估算 |
| 设置 | 绿霉概率/感染半径、自动派单开关、数据重置与技术说明 |

## 操作方式（三维巡检）

- 左键拖拽：旋转视角
- Shift + 左键拖拽：框选一批菌棒，右侧面板批量改状态
- 右键拖拽：平移
- 滚轮：缩放
- 单击：ID 缓冲拾取，弹出档案与状态时间线
- 薄膜遮挡开关：开启后棚膜写入深度，被膜/层架挡住的棒下一帧被遮挡剔除

## 关键设计

### 1. 一份记录，三处同构

`src/domain/record.ts` 定义 20 个 f32（80 字节）的菌棒记录，TS、WGSL `StickRecord`、
IndexedDB 持久化共用同一布局，全局 id 即实例序号，也是档案编号 `S000000` 的数字部分，
从根上保证拾取 id 与档案不错位。

### 2. GPU 按天推进（目标 50ms 内）

双缓冲 A/B，四个计算 pass：

1. `passAdvance` 状态机推进（含水率漂移、转色连片、潮次循环）
2. `passRemap` / `passRemapWrite` 重建全局格位映射
3. `passMold` 按相邻格位 + 棚温湿度系数做绿霉传播

完成后一次回读镜像到 IndexedDB。规则与 `src/domain/simulation.ts` 的 CPU 参考实现严格同构，
13 项逻辑测试同时约束两边的状态机、感染概率和边界条件。

### 3. GPU 驱动剔除与间接绘制

- 视锥剔除：计算着色器提取六个视锥面做球体裁剪
- 遮挡剔除：上一帧深度纹理降采样成 5 层深度金字塔（层级 Z），按外接球尺度采样保守深度
- 压缩：可见 id 原子写入连续缓冲，`writeIndirect` 回填 `drawIndexedIndirect` 参数
- 角落 HUD 实时显示剔除后实际绘制根数与帧/剔除耗时

### 4. 状态驱动外观

发菌白、转色棕褐斑块随 `colorProgress` 连片、出菇棒面菇蕾菇体随出菇天数长大、
绿霉绿斑随污染天数扩散、报废灰黑，全部在片元着色器用稳定程序噪声生成，无纹理资源。

## 性能口径与降级

- 40 万根全基地视角在支持 WebGPU 的核显上以实例化 + 计算剔除保证 30fps 目标，
  实际绘制数随视角动态收敛，HUD 可直接核对
- 不支持 WebGPU 的机器走 Canvas2D 降级，远景自动抽样，功能完整但帧率与精度降低
- 所有统计接口带脏标记缓存，避免页面重复全表扫描
